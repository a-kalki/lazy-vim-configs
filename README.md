# 💤 Моя конфигурация LazyVim

Индивидуальный стартовый шаблон для настройки Neovim на базе фреймворка [LazyVim](https://github.com/LazyVim/LazyVim). Превращает редактор в полноценную, быструю среду разработки (IDE).

## ⚡ Требования

Перед установкой убедитесь, что в вашей системе установлены:
* **Neovim >= 0.11.2** (с поддержкой LuaJIT).
* **Git >= 2.19.0** (для поддержки частичного клонирования).
* Любой шрифт из серии **Nerd Fonts** (например, *JetBrainsMono Nerd Font*) — необходим для корректного отображения иконок.
* C-компилятор (`gcc` / `clang`) для работы плагина `nvim-treesitter`.
* Утилиты для поиска (опционально, но крайне рекомендуются): `ripgrep` и `fd`.

## 🚀 Установка и развертывание

### Шаг 1: Создайте резервную копию старого конфига (если есть)
Если у вас уже был настроен Neovim, сохраните старые файлы, чтобы ничего не потерять:

```bash
# Для Linux / macOS
mv ~/.config/nvim ~/.config/nvim.bak
mv ~/.local/share/nvim ~/.local/share/nvim.bak
mv ~/.local/state/nvim ~/.local/state/nvim.bak
mv ~/.cache/nvim ~/.cache/nvim.bak
```

### Шаг 2: Клонируйте этот репозиторий
Склонируйте конфигурацию в системную папку Neovim:

```bash
git clone https://github.com/a-kalki/lazy-vim-configs ~/.config/nvim
```

### Шаг 3: Запустите Neovim
Просто введите команду запуска в терминале:

```bash
nvim
```
При первом запуске автоматически откроется менеджер пакетов `lazy.nvim`, который скачает и установит все необходимые плагины, языковые серверы (LSP) и темы. Перезапустите Neovim после окончания установки.

## 📂 Структура проекта

Конфигурация организована по официальным гайдлайнам LazyVim:

```text
~/.config/nvim
├── lua/
│   ├── config/
│   │   ├── autocmds.lua   # Автокоманды (события при сохранении, открытии файлов и т.д.)
│   │   ├── keymaps.lua     # Ваши глобальные горячие клавиши (хоткеи)
│   │   ├── lazy.lua        # Инициализация менеджера плагинов lazy.nvim
│   │   └── options.lua     # Системные настройки Neovim (табуляция, номера строк и др.)
│   └── plugins/
│       └── example.lua     # Папка для добавления, отключения или изменения плагинов
├── init.lua                # Главная точка входа для старта Neovim
└── lazyvim.json            # Настройки профилей и включенных модулей
```

## 🛠️ Кастомизация под себя

1. **Изменение системных настроек:** Откройте файл `lua/config/options.lua` и меняйте стандартные опции Vim (например, размер табов `vim.opt.shiftwidth`).
2. **Добавление горячих клавиш:** Редактируйте `lua/config/keymaps.lua` для привязки кастомных комбинаций кнопок.
3. **Установка новых плагинов:** Просто создайте любой новый `.lua` файл внутри папки `lua/plugins/` (например, `lua/plugins/ui.lua`) и опишите там настройки нужного плагина по правилам `lazy.nvim`.
4. **Управление компонентами:** Используйте встроенную команду `:LazyExtras`, чтобы в один клик включать/выключать готовые модули поддержки языков программирования (Python, TS, Go) или утилит (Docker, Copilot).
